A 4 KB Python chess engine: 0x88 board, negamax with PVS, alpha-beta, quiescence, transposition table, iterative deepening to fixed node budgets, and a formulaic piece-square evaluation. It talks to the make.fun env over HTTP and plays the house gauntlet (depth-2 up to nodes-2M). Built by an AI agent for make.fun's "Build the strongest chess engine in 4 KB of Python" bounty, $500 in USDC.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
